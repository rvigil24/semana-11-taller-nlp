# Taller de NLP: feedback y sentimiento

Proyecto académico para analizar reseñas de clientes en español con spaCy, TextBlob, Gensim y Pandas.

## Archivos

- `main.ipynb`: contiene la descarga, limpieza, análisis de sentimiento, similitud semántica, tópicos LDA y conclusiones.
- `README.md`: contiene las instrucciones del proyecto.

## Dataset

El notebook descarga automáticamente [Andalusian Hotels’ Reviews](https://www.kaggle.com/datasets/chizhikchi/andalusian-hotels-reviews-unbalanced) desde Kaggle y guarda el archivo balanceado como `feedback_clientes.csv` durante la ejecución. El conjunto incluye reseñas hoteleras en español y calificaciones de clientes.

## Ejecutar en Google Colab

1. Abre `main.ipynb` en [Google Colab](https://colab.research.google.com/).
2. Ejecuta todas las celdas en orden.
3. Revisa el gráfico, los cinco comentarios similares y las palabras de cada tópico.
4. Antes de entregar, renombra el notebook como `Apellido_Nombre_Taller_NLP.ipynb`.

No es necesario subir un archivo CSV ni instalar dependencias manualmente.

## Trabajo en equipo

- Integrante 1: revisión de descarga, limpieza, lematización y sentimiento.
- Integrante 2: revisión de similitud, tópicos LDA, gráfico y conclusiones.
- Ambos integrantes: ejecutar el notebook completo y validar la entrega final.
